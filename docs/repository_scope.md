# Repository Scope

This repository is a public-safe documentation and presentation repository only.
It contains no DroneOS implementation source code, no production flight logic,
no operational credentials or secrets, and no private DroneOS-Lab source code.

## What This Repository Contains
- high-level project status and architecture descriptions
- roadmap milestones and validation guidance
- safety notes and collaboration guidelines
- public-safe notes about the solar inspection MVP direction
- no runnable backend, PX4 bridge, planner, or vehicle-agent code

## What This Repository Does Not Contain
- DroneOS implementation source code
- executable production or prototype scripts
- PX4 mission execution logic for real aircraft
- private `.env` files, credentials, or operational logs
- code synchronized with the private DroneOS-Lab development repository

## Public-Safe Use
This repository is intended for:
- grant reviewers
- collaborators and partners
- architecture and status presentations
- early-stage pilot discussions

It is not intended for real operational deployment or to run as a flight system.
